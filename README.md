# Historical Dates Project

This project is a React-based interactive block with historical dates.

## Features
- Interactive circular navigation for time intervals (2 to 6 intervals).
- GSAP animations for the circle and year transitions.
- Swiper slider for events within each interval.
- Responsive design (Desktop and Mobile).

## Technologies Used
- React.js
- TypeScript
- styled-components
- GSAP
- Swiper
- Webpack

## Getting Started

### Prerequisites
- Node.js (v14 or higher recommended)
- npm

### Installation
1. Clone the repository (if applicable).
2. Install dependencies:
```bash
npm install
```

### Running the Project
To start the development server:
```bash
npm start
```
The application will be available at `http://localhost:3000`.

### Building for Production
To build the project for production:
```bash
npm run build
```
The output will be in the `dist` directory.
